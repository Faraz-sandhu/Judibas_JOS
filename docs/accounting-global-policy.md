# Global Accounting policy

Super Admin controls a single approval policy and expense voucher saving window for all existing and future companies from Company books. Currency, books start date and period lock remain company-specific.

Migration adopts the most recently saved company policy. Global changes are audited and increment existing company settings versions to reject stale saves. Non-Super Admin requests cannot change the global policy. Pakistan time is authoritative for expense hours; Super Admin is exempt.

New submissions use the current global selection. Existing active approval requests remain protected until completed or withdrawn, even if their document type is later unticked. Drafts remain excluded from financial reports.
