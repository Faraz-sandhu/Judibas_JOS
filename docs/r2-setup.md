# Private Communication attachment backup using Cloudflare R2

R2 Standard includes a monthly free allowance, not unlimited storage. Existing data counts toward the next month's allowance. Excess storage and requests are billed. Check https://developers.cloudflare.com/r2/pricing/ and the dashboard before enabling billing.

1. Open Cloudflare dashboard > Storage & databases > R2 and activate the subscription (review checkout/billing).
2. Create a **Standard**, private bucket named judibas-attachments. Leave public access/r2.dev disabled.
3. Create an R2 API token with Object Read & Write permissions restricted to that bucket. Copy the access key ID, secret key and account S3 endpoint.
4. Set these variables in your local/server .env. Never commit credentials:

```dotenv
COMMUNICATION_ATTACHMENTS_DISK=r2
R2_ACCESS_KEY_ID=your-access-key
R2_SECRET_ACCESS_KEY=your-secret-key
R2_BUCKET=judibas-attachments
R2_ENDPOINT=https://YOUR_ACCOUNT_ID.r2.cloudflarestorage.com
```

5. Run:

```sh
php artisan config:clear
php artisan communication:storage-check
php artisan queue:work database --queue=attachments --tries=5 --timeout=60
```

Keep the worker running in its own terminal locally; use a service/process manager in production. Restart workers after configuration changes with php artisan queue:restart.

To back up older attachments, run php artisan communication:sync-attachments once after setup. This command queues all active attachments, so avoid repeatedly running it on a large installation.

## What happens if something fails?

Uploads save to private local storage first. The worker mirrors messages, forwarded attachments, announcements and status files to R2. A cloud outage or stopped worker does not block chat sending or local attachment display. Failed jobs retry after 30, 120, 300 and 900 seconds. Inspect php artisan queue:failed and retry specific jobs with php artisan queue:retry JOB_ID after fixing the cause. If queue insertion fails, a warning is logged; run the sync command to backfill.

Downloads remain authenticated Laravel routes served from local storage. After a successful cloud mirror, image and status media previews receive a five-minute signed private R2 URL. The browser retries the authenticated local preview once if cloud playback/loading fails. If a local file is missing, the server attempts to restore it from private R2; if both copies are unavailable, the attachment returns 404. Authorization is checked before recovery. Retaining local copies costs server disk space and original downloads still use server bandwidth; media previews can load directly from R2. Thumbnails are not generated by this change.

Deletion and expired-status cleanup queue R2 deletion. During an outage a private orphan may remain until the job succeeds. If queuing deletion itself fails, the log warns and remote cleanup needs manual attention. Keep the hourly Laravel scheduler running: php artisan schedule:work locally. Do not delete local backups to save disk without a separate retention/delivery design.

Set COMMUNICATION_ATTACHMENTS_DISK=local to stop new cloud work; already queued jobs still need draining or cancelling deliberately. Configure usage alerts in Cloudflare and monitor server disk space; this app does not impose a hard R2 billing cap.
