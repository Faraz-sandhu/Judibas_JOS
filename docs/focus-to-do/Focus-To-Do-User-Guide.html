Focus To Do kya hai?

Apne kaam plan karein, ek waqt mein ek kaam par focus karein aur apni progress dekhein.

Simple example

Aap ne client ki proposal banani hai. Pehle task banayein, phir us task par 25 minutes ka timer lagayein. Session ke baad break lein. Kaam mukammal ho to task tick karein. Reports mein aapka recorded focus time nazar aayega.

Is product mein 3 basic cheezein samajh lein

NaamMatlab
TaskJo kaam karna hai: misal ke taur par ?Client proposal tayyar karni hai?.
ProjectRelated tasks ka group: misal ke taur par ?Website Launch?.
Focus sessionKisi task par timer ke saath kaam karne ka ek period.
Task banayein?Timer chalayein?Break lein?Task complete karein?Report dekhein

Product kaise kholein?

  1. Apne existing Judibas account se login karein.
  2. Products ? Focus To Do select karein, ya header ke application menu se kholein.
  3. Local PC par direct address: http://127.0.0.1:8000/focus-to-do
Access: Agar Focus To Do nazar nahi aata to administrator se product access assign karwayein. Naya alag account banane ki zaroorat nahi.

Privacy ka simple rule

Aapke tasks, notes aur personal reports aapke account ke hain. Super Admin ka apna personal Focus workspace hai; usay automatically sab employees ke tasks nazar nahi aate. Groups aur Ranking mein permitted company members ke names aur aggregate focus time nazar aate hain.

Pehla task: 5-minute practice

Pehle is example ko follow karein. Is se aapko basic workflow samajh aa jayega.

  1. Today kholein.
    Sidebar mein Today par click karein.
  2. Task likhein.
    ?Add a task and press Enter? field mein Client proposal tayyar karni hai likhein. Enter dabayein ya Add task click karein.
  3. Task details kholein.
    Task ke naam ya us ke three-dot button par click karein.
  4. Details set karein.
    Priority: High. Estimated focus sessions: 2. Due date: aaj ki date. Notes mein zaroori points likhein.
  5. Chhote steps banayein.
    + Add subtask se ?Requirements check?, ?Proposal draft? aur ?Final review? add karein. Save changes click karein.
  6. Focus start karein.
    Task ke saamne Focus button ? Pomodoro ? Start focus.
  7. Kaam complete karein.
    Jab asal kaam mukammal ho jaye to task ke saamne checkbox tick karein. Completed list mein task mil jayega.
Important: Timer finish hona aur task complete hona alag cheezein hain. Ek task ke liye kai focus sessions lag sakte hain. Timer task ko automatically complete nahi karta.

Estimate ka matlab

Agar focus duration 25 minutes hai aur estimate 2 sessions hai, estimated time 50 minutes hai. Yeh planning estimate hai; aapka actual focused time timer se record hota hai.

Testing tip: Settings ? Timer mein focus duration 1 minute set karke Save preferences karein. Phir naya session start karein. Test ke baad 25 minutes wapas kar dein.

Timer aur breaks kaise chalte hain?

Pomodoro fixed duration hai; stopwatch mein time zero se upar barhta hai.

Timer start karna

  1. Task ke saamne Focus click karein, ya sidebar mein Timer kholein.
  2. Apna unfinished task select karein.
  3. Pomodoro ya Stopwatch select karke Start focus click karein.
  4. Ek waqt mein sirf ek active timer chal sakta hai. Task change karne se pehle current session finish/stop karein.
Button / optionAsar
PauseTimer temporarily rukta hai; paused time focus mein count nahi hota.
Start / resumePaused timer continue karein ya ready break start karein.
Finish sessionCurrent focus session end karein. Jo elapsed time hua woh record rehta hai; task khud complete nahi hota.
Skip breakCurrent break end karke agla focus session manually start kar sakte hain.
ResetCurrent session cancel karke usi timer ko zero se ready karta hai. Cancelled session ka time reports mein count nahi hota.
Full screenTimer ko distraction kam karne ke liye full screen mein dikhata hai.
Mini timerDoosri Focus screen par jane ke baad neeche timer dikhta hai. Is par click karke Timer screen wapas kholein.

Default break cycle

25 min focus ? 5 min short break

4 full Pomodoro sessions ke baad short break ki jagah 15 min long break milta hai. Automatic starts off hon to ready timer ko khud Start / resume karein.

Stopwatch: Fixed 25-minute countdown ke bajaye elapsed time barhta hai. Kaam ke baad Finish session karein. Safety limit 24 hours hai.

Refresh / browser close: Running session server time se track hota hai; screen refresh se zero nahi hota. Browser band hone par sound nahi bajega. System aapki absence mein kai completed sessions invent nahi karta.

Sound: Settings mein ambience/alarm choose karein. Timer par Play selected ambience ya Mute use karein. Browser sound ko pehle user click ki zaroorat ho sakti hai.

Reports kaise dekhein?

  1. Reports kholein; From aur To dates set karke Update report click karein.
  2. Today, This week, Lifetime aur selected range ke totals dekhein.
  3. Focus over time mein Daily / Weekly / Monthly / Yearly grouping choose karein.
  4. Project distribution se pata chalega time kis project par laga. Focus by hour aur goal calendar se apni routine samjhein.
  5. Recent focus records mein task, started time, duration aur source dekhein. Previous / Next se purane records dekhein.
Break time focus total ka hissa nahi hai. Daily dates/hours Settings wali timezone ke mutabiq calculate hote hain.

Groups, Forest aur Ranking

Yeh features motivation aur company-level focus comparison ke liye hain.

Groups

  1. Groups kholein aur assigned company select karein.
  2. My groups mein joined groups; Discover mein available company groups dekhein.
  3. + Create group se name aur description de kar naya group banayein.
  4. Join group / Leave se membership manage karein. Members se members aur unka aggregate focus time dekhein.
  5. Group owner apna group Delete kar sakta hai. Search se group dhoondein.
Group mein aapke personal task titles aur notes share nahi hote. Company assign na ho to admin se assignment karwayein. Groups chat/messaging ka replacement nahi hain.

Ranking

Company aur Last 30 days / Overall select karein. List mein position, member name aur recorded focus time hota hai; apni row par (You) nazar aata hai. Sirf active permitted Focus users included hote hain. Manual records ranking mein shamil nahi.

Forest

Forest aapki consistency ko sunlight points aur growth level ke taur par dikhata hai. Available points lene ke liye Collect ?g sunlight click karein.

ActivitySunlight
Daily visit30g, ek din mein ek martaba.
Consecutive-day visitPichlay din bhi visit kiya ho to 6g extra.
Full focus session completeHar full focused minute ke liye 1g.
GrowthHar 600g collected sunlight par next level.

Activity list se earned aur collected points dekhein. Manual entries points nahi detin. Session ko beech mein Finish karna, full timer completion reward ke barabar nahi.

Notifications aur Sync

Header mein Notifications se reminders aur session completion notices dekhein. Kisi task notification par click karne se related task open ho sakta hai. Mark all read unread state clear karta hai. Enable browser alerts ke baad browser ki permission allow karein.

Sync now latest server data load karta hai. Live sync ke liye project ka existing realtime service running hona chahiye. Browser band ho to desktop popup ki guarantee nahi; notification inbox baad mein check karein.
